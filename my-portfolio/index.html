PythonJSON
View on GitHub
Problem
Member step counts, fasting habits and skill-class enrollments sat in separate raw feeds, so seeing how the community was doing meant adding things up by hand.
Solution
A Python terminal dashboard and data pipeline that fetches member, weekly and skills data, turns it into KPIs, draws ASCII charts and exports a JSON summary, using only the standard library.
Result
One screen showing who hit the step goal, the best day of the week and the most popular skill class, plus a JSON export ready for an API or dashboard.
data-analysis-report.py Data analysis

28-Day Fitness Data Analysis

PythonPandasNumPy
View on GitHub
Problem
A month of fitness log data (steps, sleep, water, fasting protocol and bench press) sat as raw numbers with no clear view of the trends.
Solution
A Python script that builds a Pandas DataFrame from the log, filters and groups it, runs NumPy statistics and prints a formatted terminal report.
Result
Clear answers to questions such as how many days hit 10,000 steps and 7.5 hours of sleep, how OMAD and 2MAD compare, and how bench press loads moved week by week.
