# Branham Simiyu — Developer Portfolio

A responsive, high-performance personal developer portfolio built with semantic HTML5, modern CSS3, and vanilla JavaScript. Features an integrated VS Code-styled interactive terminal, category filtering, a command palette, dark/light themes, and PWA capabilities.

🌐 **Live URL:** [https://branhamsimiyu8289.github.io/](https://branhamsimiyu8289.github.io/)

---

## ✨ Key Features

- **VS Code-Themed Interactive Terminal:**
  - Execute commands (`help`, `whoami`, `about`, `skills`, `projects`, `filter <category>`, `experience`, `testimonials`, `stats`, `theme`, `clear`).
  - Realistic multi-tab panel: Terminal, Problems (0 errors, 0 warnings), Output, Debug Console, and Forwarded Ports (`:8000`, `:8080`).
- **Interactive Project Filtering:**
  - Dynamic filtering by domain: `All Projects (7)`, `Python & APIs (4)`, `Web & PWAs (3)`, `Data & ML (2)`.
  - Live modal previews and CLI outputs for terminal projects.
- **Developer Journey & Timeline:**
  - Git commit-style journey showing career path, AI Masterclass specialization, and full-stack engineering milestones.
- **Client & Collaborator Reviews:**
  - Verifiable client feedback and peer testimonials.
- **Command Palette (`Ctrl+K` or `⌘K`):**
  - Instant keyboard-driven navigation across sections, direct project jumps, and filter toggles.
- **Live Status Indicator:**
  - Pulsing status dot displaying current freelance and role availability.
- **Code Snippet Quick Copy:**
  - One-click copy for the `about.py` developer dictionary.
- **Adaptive Themes:**
  - Dark and Light mode with persistent local storage and no-flash initial paint.
- **GitHub Pages Ready:**
  - Configured with `.nojekyll`, SEO meta tags, OpenGraph protocol, Twitter Cards, `robots.txt`, and `sitemap.xml`.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+), FontAwesome Icons, Google Fonts (Bricolage Grotesque & IBM Plex Mono)
- **Design Philosophy:** Developer-centric editor window aesthetics, accessible contrast, smooth entrance animations, reduced-motion compatibility
- **Hosting & CI/CD:** GitHub Pages / Vercel

## 🚀 Local Development

To run or preview the portfolio locally:

```bash
# Clone the repository
git clone git@github.com:branhamsimiyu8289/AI-Masterclass-II.git

# Navigate to the portfolio folder
cd "AI-Masterclass II/my-portfolio"

# Start a local HTTP server using Python
python -m http.server 8080

# Open in your browser:
# http://127.0.0.1:8080
```

## 📂 Project Structure

```
my-portfolio/
├── .nojekyll          # Disables Jekyll processing on GitHub Pages
├── index.html         # Main markup, semantic sections, and modal dialogs
├── styles.css         # Styling, tokens, editor windows, grid, animations
├── script.js          # Interactive terminal, palette, filters, animations
├── theme.js           # Pre-paint theme initializer
├── noscript.css       # Fallback styles when JS is disabled
├── robots.txt         # Search crawler directives
├── sitemap.xml        # Search engine sitemap
└── README.md          # Project documentation
```
